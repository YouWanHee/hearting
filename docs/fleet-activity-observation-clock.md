# 느린 수집 중 발생한 활동의 판정 시각

2026-09-14. Fleet 실행 관측 수정의 후속 보완이다. collector가 수집 시작 때
잡아 둔 `now`를 로그 읽기 이후에도 사용하면, 수집 중 생성된 실제 이벤트가
그 시각보다 늦어 ‘미래 시각’으로 배제될 수 있다. NAS 대기가 이 간격을 키운다.

활동 로그와 실행 증거를 읽은 뒤 판정 시각을 다시 잡도록 바꿨다. 미래 시각을
허용하거나 활동 유효 시간을 늘리는 대신, 읽기와 판정의 순서를 맞춘 것이다.
회귀는 실제 collector 경로에서 수집 중 시계와 로그가 전진하는 조건을 만들고
대기 phase의 owner가 working으로 표시되는지 검사한다. 이전 코드는 idle이었다.
기존의 미래·오래된 이벤트 거부 검사도 유지된다.

관련 collector, 활동, 상태 모델 3개 suite가 격리 runner에서 재시도 없이 통과했다.
원 owner/원장/pin은 수정하지 않으며, 첫 수정과 이 보완을 함께 설치한다.
